## Мета

Ознайомитися з базовим workflow задачі класифікації: від вибору та аналізу
даних до навчання, налаштування, порівняння та оцінювання моделей машинного
навчання з використанням бібліотеки scikit-learn.

## Завдання

Обрати датасет для задачі класифікації та виконати:

1. завантаження та первинний аналіз даних;
2. попередню обробку: пропуски, кодування категоріальних ознак;
3. EDA: heatmap кореляцій, гістограми, boxplot-и відносно цільової змінної;
4. поділ на train/test і масштабування ознак;
5. навчання kNN, Decision Tree, SVM, Random Forest та AdaBoost;
6. підбір `n_neighbors` для kNN і `C`, `gamma` для SVM через `GridSearchCV`.

## Датасет

[Ethereum Fraud Detection](https://www.kaggle.com/datasets/vagifa/ethereum-frauddetection-dataset) —
9 841 акаунт мережі Ethereum, 50 ознак поведінки акаунта, цільова змінна
`FLAG` (22.1 % шахрайських акаунтів).

## Результати

F1-macro на тестовій вибірці (базова лінія за accuracy — 0.7786):

| Модель | Параметри | Accuracy | F1-macro |
|--------|-----------|----------|----------|
| AdaBoost | 200 оцінювачів | 0.9935 | **0.9905** |
| Random Forest | 300 дерев | 0.9919 | 0.9881 |
| SVM (RBF) | C = 1000, gamma = 0.001 | 0.9874 | 0.9815 |
| Decision Tree | за замовчуванням | 0.9866 | 0.9806 |
| kNN | k = 5 | 0.9854 | 0.9784 |

## Основні висновки

- **Витік мітки.** Службові колонки `Unnamed: 0` та `Index` кодують клас
  напряму: рядки відсортовані за класом, а `Index` нумерується всередині
  кожного класу окремо. Дерево лише на цих двох колонках дає F1-macro = 0.9997,
  тому вони видалені до будь-якого аналізу.
- **Пропуски як артефакт.** Усі 829 акаунтів без ERC20-даних — шахрайські,
  тоді як серед 4 399 акаунтів із явним нулем ERC20-транзакцій шахраїв немає.
  Отже, пропуск тут — особливість складання датасета, а не поведінка.
- **Чесна оцінка якості.** Без ERC20-ознак Random Forest дає 0.9121 проти
  0.9862 з ними. Результат ~0.99 значною мірою спирається на згаданий
  артефакт, тому реалістичною оцінкою є ~0.91.

Числа отримано на scikit-learn 1.9.0. У Colab (scikit-learn 1.6.1) усі
висновки відтворюються; розходяться лише AdaBoost (F1 = 0.9893) і
крос-валідаційна оцінка в абляції — через зміну версії бібліотеки.

## Мета

Ознайомитися з базовим workflow побудови та навчання нейронних мереж для різних
типів даних — табличних даних, зображень і текстів; дослідити процес навчання
моделей і порівняти нейромережеві підходи з класичними алгоритмами машинного
навчання.

## Завдання

1. **Повнозв'язана мережа (MLP)** на датасеті з лабораторної № 1, learning
   curves, аналіз перенавчання, порівняння з класичними алгоритмами.
2. **Згорткові мережі** на датасеті зображень: проста CNN з нуля та донавчена
   pretrained-модель; порівняння якості, збіжності, learning curves і впливу
   обсягу даних.
3. **Рекурентні мережі** для текстів з лабораторної № 2: токенізація, словник,
   padding; LSTM з випадковими ембедингами та з GloVe.

## Датасети

- [Ethereum Fraud Detection](https://www.kaggle.com/datasets/vagifa/ethereum-frauddetection-dataset) — табличні дані (частина 1).
- [Malimg](https://www.kaggle.com/datasets/ikrambenabd/malimg-original) — 9 339
  зображень шкідливих програм (байти виконуваного файла як пікселі), 25 родин
  (частина 2). 895 точних дублікатів прибрано до поділу на вибірки.
- [CVE & CWE Dataset (1999–2025)](https://www.kaggle.com/datasets/stanislavvinokur/cve-and-cwe-dataset-1999-2025) —
  описи вразливостей, класи MEDIUM / HIGH / CRITICAL (частина 3).
- [GloVe](https://nlp.stanford.edu/projects/glove/) — Wikipedia 2014 + Gigaword 5, 100 вимірів.

## Основні результати

| Задача | Модель | F1-macro (тест) |
|---|---|---|
| Ethereum | MLP з регуляризацією | 0.9814 |
| | AdaBoost / Random Forest (ЛР1) | 0.9905 / 0.9881 |
| Malimg | CNN з нуля (3 seed) | 0.906 ± 0.017 |
| | ResNet18, донавчена (3 seed) | 0.983 ± 0.001 |
| CVE | BiLSTM, випадкові ембединги (3 seed) | 0.683 ± 0.015 |
| | BiLSTM, GloVe (3 seed) | 0.683 ± 0.013 |
| | TF-IDF + Linear SVM (ЛР2) | 0.701 |

- **MLP** не перевершує ансамблів дерев на табличних даних. Без регуляризації
  валідаційний loss зростає з 6-ї епохи, але F1 — ні: мережа стає надмірно
  впевненою, не змінюючи рішень.
- **Pretrained ResNet18** переважає CNN з нуля за якістю, швидкістю збіжності
  (F1 = 0.91 уже після першої епохи) і стабільністю. Найбільше — на малих
  даних: на 295 зображеннях 0.87 проти 0.56. Майже всі залишкові помилки — між
  варіантами однієї родини шкідливого ПЗ.
- **GloVe** на повних даних нічого не дає, на малих — невелику перевагу (+0.02
  на 573 описах). GloVe не знає ключових термінів безпеки (*csrf*, *ssrf*,
  *deserialization*). Для коротких шаблонних описів TF-IDF кращий за BiLSTM.
